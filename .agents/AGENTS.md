# DlyMinder – Health Tracker

## Tech Stack
- Flutter 3.x / Dart 3.10.8
- State Management: Provider
- Database: Drift (SQLite) with code generation
- Backend: Firebase (Auth, Firestore, Storage, App Check)
- On-device AI: flutter_gemma (Android-only, vendored)
- Notifications: flutter_local_notifications + android_alarm_manager_plus

## Architecture
- `lib/core/` → Shared services, database, AI, theme, utils, widgets
- `lib/features/` → Feature-based modules (medication, water, sleep, focus, steps, period, insights, reminders, settings, backup, onboarding, home)
- `lib/widgets/` → Global reusable widgets

## Critical Rules
- NEVER modify `*.g.dart` files — they are auto-generated by `drift_dev`
- Run `dart run build_runner build` to regenerate database code
- Firebase project config is in `firebase.json`, `firestore.rules`, `storage.rules`
- `flutter_gemma` is vendored in `third_party/flutter_gemma` (iOS plugin stripped)
- Always use `super.key` in widget constructors
- Production URL: Dlearn.info | Local: http://localhost:5173/

## Build Commands
- `flutter pub get` — Install dependencies
- `dart run build_runner build --delete-conflicting-outputs` — Regenerate code
- `flutter build apk --release` — Android release build
- `flutter build ios --release` — iOS release build
- `flutter test` — Run unit tests
- `flutter analyze` — Run static analysis
